- `index.html` 1ファイルに全24ページが入っています。
  - トップ / ご利用案内 / 採用トップ / 募集要項15(広報のSNS運用・記事制作、動画撮影・編集を含む)

  - 報道・メディアの方へ / 個人情報の取り扱い

- 「事業承継・M&A」ページの「譲渡の相談窓口」フォームは、`send-transfer.php` から t-izuhara@try-support.com に届きます(アドレスはページに出ません)。PHPが使えるサーバーに、`index.html` と同じ場所へ置いてください。公開したら、1回テスト送信して届くか確かめてください。

- 検索エンジンに載らない設定(noindex)が入っています。本番用には、noindexのない版を使ってください。
- 旧デザイン版は `steps-support-site` フォルダに残しています。
- 求人の構造化データ(Googleしごと検索用のJobPosting)は `data/jobposting.json` にあります。`datePosted`(掲載日)には、公開する日を入れてください。募集の期限を決めていないので、募集終了日(`validThrough`)は入れていません。採用が決まった求人は、ページとデータの両方から消してください。

## GitHub Pages でテストする

1. GitHubで新しいリポジトリを作り、このフォルダの中身をそのまま入れます(`index.html` がいちばん上に来るように)。
2. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存します。
3. 数分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` で確認できます。

- `.nojekyll` は、GitHub Pages にファイルをそのまま公開させるためのものです。消さないでください。
- ページの `<head>` に noindex(検索エンジンに載せない設定)を入れています。`robots.txt` は使っていません。GitHub Pagesの「ユーザー名.github.io/リポジトリ名/」では robots.txt が読まれないためと、robots.txt でアクセスを止めると noindex の指示自体が検索エンジンに届かなくなるためです。
- GitHub Pages ではPHPが動かないため、譲渡の相談フォーム(`send-transfer.php`)はテスト環境では送信できません。送信の確認は本番のサーバーで行ってください。
- 無料プランのGitHub Pagesは、リポジトリを公開(Public)にする必要があります。URLを知っている人は見られる状態になります。
